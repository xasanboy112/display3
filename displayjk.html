⚙️ Hardware Engineering & OS Architectures

Core Core Processing Components

Computing architecture relies on the execution cycle of the Central Processing Unit (CPU). The CPU functions using a three-part execution path: **Fetch** (pulling instructions from RAM), **Decode** (translating data commands via the control unit), and **Execute** (running calculations inside the Arithmetic Logic Unit, or ALU).

Memory Volatility Hierarchy

Computer structures organize data storage pipelines into specific layers based on speed and cost factor attributes:

  • L1/L2/L3 Caches: Ultra-fast SRAM (Static RAM) memory pipelines built straight onto the silicon CPU structure.
  • System RAM: Dynamic RAM (DRAM), a volatile storage zone that holds active configuration lines while checking instruction logs. It drops all registers instantly when electricity shuts down.
  • Solid State Storage (SSD): Non-volatile NAND flash memory arrays that store documents using non-volatile charge traps, retaining information long-term.

Operating System Kernels

The Operating System (OS) kernel manages application instructions and physical system hardware channels. It acts as the core supervisor, managing hardware interrupts, allocating process execution slots, and partitioning file sectors securely.

Core Hardware Terms

  • Motherboard: The central printed circuit board linking system buses.
  • BIOS/UEFI: Built-in firmware that initializes hardware checks during power startup.
  • RAM: Random Access Memory.

Core Port Mapping Protocols

Every internet connection uses specific port numbers at the Transport Layer to guide data packages to the right system services:

  • Port 22 (SSH): Secure Shell. Establishes encrypted remote terminal control lines.
  • Port 53 (DNS): Domain Name System. Translates readable domains directly into underlying IP addresses.
  • Port 80 & 443: HTTP (unencrypted text delivery) and HTTPS (secure web connections utilizing TLS encryption layers).

Device Operations

  • Router: Interconnects disparate IP networks.
  • Switch: Learns device MAC locations to switch data locally.
  • DHCP: Automatically leases IP addresses to system clients.

💻 Software Development Paradigms

Programming Translation Models

Developers write human-readable source code instructions, which must be processed down into low-level binary code (zeros and ones) through two primary translation methods:

Compiled Languages (e.g., C++, Rust): A compiler parses the entire application code file beforehand, converting it all into a single, high-performance machine executable block. This file runs incredibly fast but must be recompiled for different operating systems.

Interpreted Languages (e.g., Python, JavaScript): An interpreter reads and executes the code line-by-line at runtime. This model provides excellent flexibility and allows you to test scripts instantly, but it introduces minor speed performance costs.

The Modern Web Architecture Framework

Web applications split tasks between two distinct execution layers:

  • Frontend Stack: Runs directly inside the user's web browser. It relies on HTML to define content layout, CSS to manage visual design and styles, and JavaScript to handle page interaction logic.
  • Backend Infrastructure: Processes complex workflows away from public view. Servers run programming languages like Python or Node.js to compute data and connect directly with core database arrays (such as PostgreSQL or MongoDB).

Dev Core Skills

  • Data Structures: Arrays, Lists, and Dictionaries organize file records cleanly.
  • Git Version Control: Tracks and logs every line change, preventing code conflicts.

🔒 Information Security Foundations

The Fundamental CIA Triad

Cyber defense teams use three core pillars as a blueprint to secure system architectures and protect confidential enterprise assets:

Confidentiality: Locking down access privileges so sensitive files remain invisible to unapproved user accounts (enforced through multi-factor authentication and data encryption).

Integrity: Protecting files against unauthorized tampering or modification, ensuring records stay authentic (verified using hashing algorithms like SHA-256).

Availability: Keeping network systems and services accessible to authorized employees around the clock (maintained through power backups and redundant servers).

Deconstructing Encryption Methods

Encryption scrambles legible text files into unreadable blocks of random characters to keep data safe. This is achieved using two main cryptographic approaches:

  • Symmetric Cryptography: Both the sender and the receiver use the exact same secret key to encrypt and decrypt the data. This method is incredibly fast but requires a secure way to share the key beforehand (e.g., AES encryption).
  • Asymmetric Cryptography: Uses a linked pair of mathematically related keys. The **Public Key** can be shared openly with anyone to encrypt data, but only the corresponding private **Private Key** can decrypt it (e.g., RSA encryption algorithms).

Vector Defense

  • Phishing: Fraudulent emails used to steal login credentials.
  • Firewall: A network filter that blocks unapproved traffic.
  • MFA: Multi-Factor Authentication.

☁️ Cloud Architectures & Virtualization Systems

The Power of Virtualization

Virtualization allows you to run multiple independent operating systems simultaneously on a single physical server. This technology relies on a software abstraction layer called a **Hypervisor**:

Type 1 (Bare-Metal Hypervisors): Installs and runs directly on top of the physical server hardware (e.g., VMware ESXi). This approach offers maximum performance and is the standard choice for enterprise data centers.

Type 2 (Hosted Hypervisors): Runs as an application layer on top of an existing operating system (e.g., VirtualBox running on Windows). This setup is ideal for developer testing environments but introduces minor performance overhead.

Cloud Delivery Models

Cloud computing transforms fixed hardware expenses into scalable, pay-as-you-go service models over the internet:

  • IaaS (Infrastructure as a Service): Provides raw computing power, virtual servers, and storage space. You retain full control over the operating system and software configuration (e.g., AWS EC2).
  • PaaS (Platform as a Service): Delivers a pre-configured environment optimized for building software. The underlying OS and server maintenance are completely managed for you (e.g., Heroku).
  • SaaS (Software as a Service): Provides a fully functional web application accessible directly through your browser. Requires zero system management on your end (e.g., Google Workspace).

Cloud Definitions

  • Scalability: The ability to instantly scale up server resources on demand.
  • Containers: Lightweight isolation engines (like Docker) that package app code.
